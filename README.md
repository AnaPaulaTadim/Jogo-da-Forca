#  Jogo da Forca em Java (Swing / GUI)

Um clássico **Jogo da Forca** desenvolvido em **Java** com interface gráfica para proporcionar uma experiência interativa e amigável.

---

## 🎯 Sobre o Projeto

O objetivo do jogo é adivinhar a palavra secreta letra por letra antes que o número máximo de tentativas se esgoste e a figura do enforcado seja completada.

### 🛠️ Funcionalidades
* **Interface Gráfica (GUI):** Construída de forma intuitiva e responsiva.
* **Desenho Dinâmico da Forca:** A figura é atualizada visualmente a cada erro cometidos.
* **Validação de Entrada:** Impede o reuso de letras já chutadas e trata caracteres inválidos.
* **Sorteio de Palavras:** Sistema de seleção aleatória de palavras cadastradas.
* **Condições de Vitória/Derrota:** Mensagens e reinício do jogo ao adivinhar a palavra ou esgotar as tentativas.
